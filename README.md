# Flores Pools & More (sample site)

A sample website I designed for Flores Pools & More, a pool service company in San Antonio, TX. I put together sites like this to show local businesses what a modern, mobile-friendly web presence could look like for them before they commit to anything.

**Live preview:** https://preview-flores-pools-more.vercel.app

## Design

A warm, handcrafted feel with Young Serif headlines, Nunito body text, and Caveat for small handwritten touches, to match a family-run local business.

## Stack

- Plain HTML and CSS in a single `index.html`, with no framework and no build step
- Responsive, mobile-first layout
- Google Fonts, plus photos from Unsplash (credited on the page)
- Hosted on Vercel

## Running it locally

Open `index.html` in a browser, or serve the folder with something like `npx serve .`

## Notes

- This is a sample site, not the business's official website, and it isn't affiliated with or published by Flores Pools & More.
- The contact form is for demo purposes only and doesn't send anything.
- Search engines are blocked for now (`robots.txt` and a `noindex` header in `vercel.json`) until the business decides whether it wants the site live.
